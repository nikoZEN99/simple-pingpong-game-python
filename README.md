# Simple Ping Pong Game (Python)

A simple Ping Pong game built with Python's built-in `turtle` graphics module.

## Features

- A movable paddle (turtle "head") controlled by the player
- A bouncing ball with basic wall and paddle collision
- Live score tracking, displayed on screen
- Ball speeds up slightly after each successful paddle hit

## Requirements

- Python 3

No external libraries needed — `turtle` ships with standard Python installs.

## Usage

```bash
python pingpong.py
```

## Controls

- **`W`** — move paddle up
- **`S`** — move paddle down
